# Abhishek Gowda — Portfolio Website

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript. Designed for GitHub Pages; no build process or backend is required.

## Quick Start

```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

## Files
- `index.html` — portfolio landing page
- `style.css` — responsive layout and visual styling, including print styles for the resume
- `script.js` — mobile navigation, reveal-on-scroll interactions, and footer year
- `resume.html` — print-friendly draft resume with a **Print / Save as PDF** button
- `assets/favicon.svg` — portfolio favicon

## Before publishing
1. Verify the education wording: BGS Institute of Technology (BGSIT), BG Nagara, Mandya, Adichunchanagiri University, 2024–2028.
2. Add your professional email address and phone number if you want them displayed.
3. Replace the generic hackathon achievement wording with the official event name, date, team, and award details.
4. Review every project description to confirm your exact contribution and current implementation status.
5. If you have a formal resume PDF, add a link to it on the home page. The current `resume.html` is an editable, print-friendly draft; open it and choose **Print / Save as PDF** to generate a PDF.
6. Review the skill list and remove any tools you are not ready to discuss during an interview.

## Publish with GitHub Pages
1. Create a new **public** repository named exactly `Abhishek71316.github.io` (if you haven't created it already).
2. Upload the contents of this folder to the repository root: `index.html`, `style.css`, `script.js`, `resume.html`, `README.md`, and `assets/`.
3. In that repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for deployment to complete. The expected website URL is `https://abhishek71316.github.io/`.
6. Open the URL on desktop and mobile; test all repository and LinkedIn links and the print-to-PDF resume page.

Official GitHub Pages guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
